# هيئة أحفاد الإمام الكاظم (ع)

الموقع الرسمي لهيئة أحفاد الإمام الكاظم (ع) في النجف الأشرف، طرف الإسكان، ويقوم عليها أولاد السيد ناصر.

يعرض الموقع سيرة الإمام موسى بن جعفر الكاظم (ع)، ومظلوميته وشهادته، ونسبه وعائلته، وتعريفًا بالهيئة ومجالسها، بهويةٍ حسينية: السواد، والدم، والذهب، والأخضر.

اللغات: العربية (الافتراضية)، والإنكليزية، والروسية، والفارسية، والأذرية.

## التقنيات

- [Vite](https://vite.dev): موقع ثابت متعدد الصفحات.
- [Three.js](https://threejs.org): الستارة الدامية والقطرات ثلاثية الأبعاد.
- [GSAP](https://gsap.com) و ScrollTrigger: الحركة مع التمرير.
- الخطوط محلية برخصة SIL OFL: الرقعة والأميري للعربية والفارسية، وCormorant Garamond وEB Garamond للإنكليزية والروسية والأذرية.

## التشغيل

يتطلب Node.js بإصدار 20.19 أو 22.12 فما فوق.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`. للمعاينة بنسخة النشر الفعلية (أسرع وأنعم):

```bash
npm run build
npm run preview
```

ثم افتح `http://localhost:4173`.

## النشر

`npm run build` يُنتج مجلد `dist/` جاهزًا لأي استضافة ثابتة، والروابط نسبية فيعمل من أي مسار.

النشر التلقائي على GitHub Pages جاهز في `.github/workflows/deploy.yml`: فعّله مرة واحدة من **Settings ← Pages ← Source: GitHub Actions**، وبعدها يُنشر الموقع مع كل دفع إلى الفرع `main`.

## الترجمة

كل صفحة قالب واحد في `src/pages/`، ونصوصها مفاتيح مثل `{{t:home.city}}` تُقرأ من `src/locales/<اللغة>.json`. عند البناء تُولَّد صفحة ثابتة لكل لغة:

| اللغة | الرابط | الاتجاه |
|---|---|---|
| العربية | `/index.html` | من اليمين |
| English | `/en/index.html` | من اليسار |
| Русский | `/ru/index.html` | من اليسار |
| فارسی | `/fa/index.html` | من اليمين |
| Azərbaycanca | `/az/index.html` | من اليسار |

- **تعديل نص:** غيّره في ملف اللغة، والصفحة تتحدّث فورًا في `npm run dev`.
- **إضافة نص جديد:** أضف المفتاح في `ar.json` وفي بقية اللغات، واستعمله في القالب بـ `{{t:المفتاح}}`.
- **التحقق:** `npm run i18n:check` يكشف أي مفتاح ناقص أو زائد أو وسم HTML غير مغلق، ويعمل تلقائيًا قبل كل بناء.
- **إضافة لغة:** أضف رمزها إلى `LOCALES` في `scripts/i18n.js`، وانسخ `ar.json` باسمها وترجمه، وحدّد في `meta` الاتجاه (`dir`) والحروف (`script`).

## تحديث الصور

ضع الصورة الأصلية في `assets-source/images/` بالاسم نفسه (والقصّ والتدوير وتصحيح الألوان لكل صورة معرّفة في `IMAGES` داخل `scripts/optimize-images.py`)، ثم:

```bash
npm run images
```

يتطلب Python 3 و Pillow (`pip install Pillow`).

## ملاحظات

- أضف `?still` في آخر أي رابط لعرض الصفحة بحالتها النهائية بلا حركة، وهذا مفيد للمراجعة واللقطات.
- صفحات اللغات تُولَّد مؤقتًا داخل `src/` أثناء البناء ثم تُحذف، وهي مستثناة من Git.
- من يفعّل "تقليل الحركة" في جهازه يرى الموقع بالحالة نفسها تلقائيًا.
- الصورة `assets-source/images/mourning-vigil.png` غير مستعملة في الموقع بعد.
